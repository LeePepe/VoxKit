# VoxKit AI and integration guide

VoxKit 0.1.0 exposes seven modules: `VoxCore`, `VoxSpeech`, `VoxSpeechWhisperKit`, `VoxRefine`, `VoxLLM`, `VoxWorkflow`, and `VoxWorkflowWhisperKit`.

- Start with `USAGE.md` for API patterns.
- Use `INTEGRATION.md` for SwiftPM setup.
- See `EXAMPLES.md` for end-to-end graphs.
- Check `COMPATIBILITY.md` before selecting optional products.
- Use `MIGRATION.md` when moving from VoxPocket internals.
- `registry.json` is the machine-readable capability index.
